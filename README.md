# NinjaTrader 8 Backup

This folder is set up as a curated Git backup for NinjaTrader 8 custom work.

The repo is intended to protect NinjaScript source, strategy templates, indicator
templates, ATM/chart/stop/risk templates, recovered templates, and standalone
strategy packs. It intentionally leaves out live platform state such as account
configuration, database files, logs, cache, trace output, temporary files, and
market data exports.

See `docs/NT8_BACKUP_PLAN.md` for the backup scope, GitHub setup, automation
steps, and restore notes.
